# 3 минимальные части

часть 1 создание команды:
кнопка создать команду
генерация короткого кода
сохранение команды в базе

часть 2 вход по коду:
поле ввода кода
проверка кода
добавление игрока в команду максимум 4

часть 3 общий счет:
баллы любого участника идут в общий счет команды
отображение общего счета всем участникам

зависимости:
часть 2 зависит от части 1
часть 3 зависит от частей 1 и 2
чат ссылки приглашения и роли не входят в минимальный вариант
