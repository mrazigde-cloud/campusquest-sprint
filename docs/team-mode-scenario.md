минимальный сценарий для четырех игроков:

1) создать команду
один игрок нажимает создать команду перед стартом квеста

2) получить код
система показывает короткий код команды например kq7p

3) присоединиться
остальные один три игрока вводят этот код и входят в команду

4) пройти станцию
любой участник команды может открыть станцию и отправить ответ

5)увидеть общий счет
баллы всех участников суммируются в один общий счет команды
