# правила минимального варианта
- максимум 4 игрока в одной команде
- команду создает один игрок перед началом квеста
- после создания появляется короткий код
- остальные игроки вводят этот код чтобы присоединиться
- любой участник команды может отправить ответ на станции
- баллы идут в общий счет команды
- чат приглашения по ссылке и роли не входят в минимальный вариант
- заказчик согласен на упрощенный вариант
